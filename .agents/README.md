# Agent skills (imported)

This tree is the project skill pack for Redplane. Canonical files live in
`.agents/skills/<name>/SKILL.md`. Cursor and Claude Code resolve the same pack
via `.cursor/skills` and `.claude/skills` (symlinks).

**Source:** copied from `halilozturkci/cyberroundtable.ai` (`.agents/skills/` +
`skills-lock.json`). Matt Pocock engineering skills are hashed in
`skills-lock.json`; additional repo skills (workflows, reviews, writing) are
kept beside them.

Do not store secrets here. Invoke a skill by reading its `SKILL.md` before
acting.
